01 / The composition boundary

Hosts describe. FSM_COS composes.

A host supplies a manifest and a catalog. FSM_COS discovers the requested dependency closure, validates the composition, loads prerequisites before dependents, and performs bounded arbitration. The host remains responsible for executing, presenting, or integrating the result.

Input

Runtime manifest

Declares the capabilities and versions the host requests, with optional configuration.

Resolution

Dependency closure

Discovers prerequisites, validates the graph, and determines a dependency-safe load order.

Output

RuntimeAssembly

Returns the composed result to the host; it does not become the host's application loop.
