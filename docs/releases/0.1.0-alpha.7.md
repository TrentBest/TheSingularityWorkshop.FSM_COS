# FSM_COS 0.1.0-alpha.7 — Release Candidate Notes

> These notes describe the source candidate's intended contract. They do not establish publication status; check the [NuGet package page](https://www.nuget.org/packages/TheSingularityWorkshop.FSM_COS) for availability.

## Why alpha.7 exists

Alpha.7 hardens the composition result and staged-plan contracts: collections exposed as read-only interfaces are now backed by read-only snapshots rather than mutable lists or arrays. A consumer can no longer cast those public collections back to their underlying mutable storage and silently alter the assembly or invalidate a dependency plan after validation.

## Included behavior

- `RuntimeAssembly.Bundles` is a read-only snapshot of the composed bundle order.
- `RuntimeManifestSchedule` exposes read-only snapshots for entries, dependency edges, independent entries, and dependent entries.
- `RuntimeManifestLoadPlan.Entries` is a read-only snapshot.
- Regression tests attempt mutation through `IList<T>` casts and verify that the collection rejects it.
- The package workflow validates both packed NuGet candidates against the project contract, including package ID/version, declared dependencies, target assembly and XML documentation, packaged README/license, release notes, and the core living diagrams.

## Package contract

- Target framework: .NET 8.
- Direct dependencies: FSM_API 1.0.13, FSM_UserIO 0.1.0-alpha.1, and MicroBundleDomain 1.0.1.
- Package version declared by this source: `0.1.0-alpha.7`.

## Explicit limitations

Alpha.7 does not implement repository localization, content-hash verification, Bootstrap-only initial composition, background localization, or live promotion of Deferred bundles into an already running `RuntimeAssembly`. The read-only wrappers protect collection structure; the MicroBundle instances themselves remain domain-owned objects and may expose their own mutable behavior.

## Publication

Publication remains a separate release action. Verify the exact commit, both package-content checks, build/test, public-package compatibility, and development-source integration before publishing. The manual `workflow_dispatch` publish input must remain deliberately selected; this document alone never authorizes publication.
