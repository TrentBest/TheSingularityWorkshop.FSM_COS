# FSM_COS source UML

> **Status:** manually authored source maps, not GUI.SVG-generated. Source baseline: `ce43e8f5bf3dfc229f28678fc2e0d944c5c8d38a`.

This directory has one companion page for each tracked C# file in the baseline: 16 runtime source files, 5 test-project files, and 2 sample files (**23 total**). Runtime pages map declarations and source-visible relationships; test pages map asserted evidence; sample pages describe examples rather than production guarantees.

## Rules for claims

- Diagrams are navigation aids, not substitutes for source.
- A declaration establishes API shape, not all runtime behavior.
- A test name or assertion supports only the behavior it actually exercises.
- External, hosted, accessibility, lifecycle, concurrency, and rollback claims remain open unless directly evidenced.
- These pages are manual and can become stale. Reconcile each against source on every change; do not claim automatic freshness.
